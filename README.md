# RefalABEinsteinPuzzle

Решение [задачи Эйнштейна](https://ru.wikipedia.org/wiki/Загадка_Эйнштейна), написанное на языке программирования [РефалАБ](https://github.com/Aleksandr3Bocharov/refalab).

Программа "RefalABEinsteinPuzzle" решает логическую задачу Эйнштейна с пошаговым выводом процесса решения.

## Особенности

- **Две версии программы:**
    - Консольная версия — вывод пошагового решения в текстовом виде;
    - GUI версия — графический интерфейс на основе библиотек [raylib](https://www.raylib.com/) и [raygui](https://github.com/raysan5/raygui) с интерактивным просмотром шагов решения;
- **Пошаговое решение** — программа показывает каждый шаг применения подсказок;
- **Интерактивный просмотр** — в GUI версии можно перемещаться между шагами решения;
- **Подсчёт шагов** — отображение количества шагов без возвращения и с возвращением;
- **Написан на РефалАБ** — демонстрация возможностей языка для решения логических задач.

## Задача Эйнштейна

**Условия**

1. Есть 5 домов разных цветов.
2. В каждом доме живет по одному человеку, отличающегося от другого по национальности.
3. Каждый обитатель пьет только один определенный напиток, курит определенную марку сигарет и держит животное.
4. Никто из пяти людей не пьет одинакового напитка, не курит одинаковые сигареты и не держит одинаковых животных.

**Вопрос**

Чья рыба?

**Подсказки**

1. Англичанин живет в красном доме.
2. У шведа есть собака.
3. Датчанин пьет чай.
4. Зеленый дом стоит слева от белого.
5. Обитатель зеленого дома пьет кофе.
6. Человек, который курит Pall Mall, держит птицу.
7. Обитатель среднего дома пьет молоко.
8. Обитатель желтого дома курит Dunhill.
9. Норвежец живет в первом доме.
10. Курильщик Marlboro живет возле того, у кого есть кошка.
11. Человек, у которого есть конь, живет возле того, кто курит Dunhill.
12. Курильщик Winfield пьет пиво.
13. Норвежец живет возле голубого дома.
14. Немец курит Rothmans.
15. Курильщик Marlboro живет по соседству с человеком, который пьет воду.

## Системные требования

### РефалАБ
- **Версия:** 2.1 или выше
- **Переменные окружения:** должны быть настроены согласно документации РефалАБ
    - `REFALABBIN` — путь к исполняемым файлам РефалАБ;
    - `REFALABCFLAGS` — флаги компилятора C;
    - `REFALABINCLUDE` — путь к заголовочным файлам;
    - `REFALABLFLAGS` — флаги компоновщика.

Подробнее см. [документацию по установке РефалАБ](https://github.com/Aleksandr3Bocharov/refalab).

### Компилятор
- Компилятор C Clang

### Для GUI версии (дополнительно)

**raylib 5.5:**

- Windows:
    - Скачать [raylib 5.5 для Windows x64 (mingw-w64)](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win64_mingw-w64.zip) или [raylib 5.5 для Windows x86 (mingw-w64)](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win32_mingw-w64.zip);
    - Распаковать в любую директорию;
    - Отредактировать `make_run_gui.bat`, изменив путь в строке на свой путь к распакованному raylib:

            set RAYLIB=F:\Programming\raylib-5.5_win64_mingw-w64

- POSIX:
    - Установить через пакетный менеджер (например, `apt install libraylib-dev` для Ubuntu);
    - Скрипт сборки использует системные библиотеки.

**raygui:**
- Включён в исходный код проекта в директории `src/raygui/`;
- Дополнительная установка не требуется.

### GUI версия

**Сборка и запуск графической версии:**

- Windows:

        make_run_gui.bat

- POSIX:

        ./make_run_gui

**Особенности GUI версии:**
- Графическое окно 1300×820 пикселей (уменьшается до 1300×550 после решения);
- Поддержка кириллицы (шрифт DejaVu);
- Частота обновления: 60 FPS.

**Порядок работы:**
1. Запустить программу;
2. Ознакомиться с условиями задачи в начальном диалоге;
3. Нажать "Решить задачу" или Enter;
4. Просмотреть пошаговое решение с таблицей;
5. Перемещаться между шагами с помощью кнопок или клавиш;
6. Нажать "Да" в диалоге подтверждения выхода.

**Управление навигацией по шагам:**

| Клавиша | Кнопка | Действие |
|---------|--------|----------|
| ↑ | ⏮ | К началу решения |
| ← | ◀ | На шаг назад |
| → | ▶ | На шаг вперёд |
| ↓ | ⏭ | К концу решения |

**Информация на экране:**
- Вопрос задачи: "Чья рыба?";
- Ответ: национальность человека, у которого рыба;
- Текущая подсказка с номером и текстом;
- Таблица с состоянием всех 5 домов;
- Количество шагов без возвращения;
- Количество шагов с возвращением.

**Выход из программы:**
- При закрытии окна появляется диалог подтверждения выхода;
- Выбрать "Да" или нажать Enter для выхода;
- Выбрать "Нет" или Escape для продолжения работы.

**Повторный запуск без компиляции:**

После первой сборки можно запускать программу напрямую:

- Windows:

        bin\refalabeinsteinpuzzle_gui.exe

- POSIX:

        ./bin/refalabeinsteinpuzzle_gui
