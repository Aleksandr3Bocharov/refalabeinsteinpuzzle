Программа **RefalABEinsteinPuzzle** решает логическую задачу Эйнштейна и выводит ход решения по шагам: каждую подсказку и таблицу домов после её применения.

## ✨ Возможности

| | |
| :--- | :--- |
| 🖥️ **Консольная версия** | Пошаговое решение в текстовом виде |
| 🪟 **GUI версия** | Графический интерфейс на [raylib](https://www.raylib.com/) и [raygui](https://github.com/raysan5/raygui) с интерактивным просмотром шагов |
| 🔍 **Пошаговое решение** | Показан каждый шаг применения подсказок |
| ⏯️ **Навигация по шагам** | В GUI можно переходить вперёд и назад по решению |
| 🔢 **Подсчёт шагов** | Количество шагов без возвращения и с возвращением |
| 🔤 **Поддержка кириллицы** | В GUI используется шрифт DejaVu |

## 🧩 Задача Эйнштейна

**Условия**

1. Есть 5 домов разных цветов.
2. В каждом доме живёт по одному человеку, отличающемуся от другого по национальности.
3. Каждый обитатель пьёт только один определённый напиток, курит определённую марку сигарет и держит животное.
4. Никто из пяти людей не пьёт одинакового напитка, не курит одинаковые сигареты и не держит одинаковых животных.

**Вопрос:** чья рыба? 🐟

<details>
<summary><b>Подсказки (15)</b></summary>

1. Англичанин живёт в красном доме.
2. У шведа есть собака.
3. Датчанин пьёт чай.
4. Зелёный дом стоит слева от белого.
5. Обитатель зелёного дома пьёт кофе.
6. Человек, который курит Pall Mall, держит птицу.
7. Обитатель среднего дома пьёт молоко.
8. Обитатель жёлтого дома курит Dunhill.
9. Норвежец живёт в первом доме.
10. Курильщик Marlboro живёт возле того, у кого есть кошка.
11. Человек, у которого есть конь, живёт возле того, кто курит Dunhill.
12. Курильщик Winfield пьёт пиво.
13. Норвежец живёт возле голубого дома.
14. Немец курит Rothmans.
15. Курильщик Marlboro живёт по соседству с человеком, который пьёт воду.

</details>

## 📋 Требования

### Для обеих версий

- **РефалАБ** версии **2.1** или выше;
- компилятор C **Clang**;
- настроенные переменные окружения (см. [документацию РефалАБ](https://github.com/Aleksandr3Bocharov/refalab)):

| Переменная | Назначение |
| :--- | :--- |
| `REFALABBIN` | путь к исполняемым файлам РефалАБ |
| `REFALABCFLAGS` | флаги компилятора C |
| `REFALABINCLUDE` | путь к заголовочным файлам |
| `REFALABLFLAGS` | флаги компоновщика |

### Дополнительно для GUI версии

**raylib 5.5**

<details>
<summary><b>🪟 Windows</b></summary>

1. Скачайте [raylib 5.5 для Windows x64](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win64_mingw-w64.zip) или [для Windows x86](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win32_mingw-w64.zip) (mingw-w64);
2. Распакуйте архив в любую директорию;
3. В `make_run_gui.bat` замените путь в строке на свой:

```bat
set RAYLIB=F:\Programming\raylib-5.5_win64_mingw-w64
```

</details>

<details>
<summary><b>🐧 POSIX (Linux / macOS)</b></summary>

Установите raylib через пакетный менеджер, например для Ubuntu:

```sh
apt install libraylib-dev
```

Скрипт сборки использует системные библиотеки.

</details>

**raygui** уже включён в проект (`src/raygui/`), отдельная установка не нужна.

### Консольная версия

Скрипт компилирует исходники РефалАБ, создаёт `bin/refalabeinsteinpuzzle` и запускает его. Программа сама решает задачу, аргументы не нужны.

```sh
./make_run          # POSIX
make_run.bat        # Windows
```

### GUI версия

```sh
./make_run_gui          # POSIX
make_run_gui.bat        # Windows
```

Окно 1300×820 пикселей (после решения уменьшается до 1300×550), 60 FPS, поддержка кириллицы.

**Порядок работы**

1. Запустите программу;
2. Ознакомьтесь с условиями задачи в начальном диалоге;
3. Нажмите «Решить задачу» или `Enter`;
4. Просмотрите пошаговое решение с таблицей;
5. Перемещайтесь между шагами кнопками или клавишами;
6. При выходе подтвердите закрытие кнопкой «Да».

**Навигация по шагам**

| Клавиша | Кнопка | Действие |
| :---: | :---: | :--- |
| `↑` | ⏮ | к началу решения |
| `←` | ◀ | на шаг назад |
| `→` | ▶ | на шаг вперёд |
| `↓` | ⏭ | к концу решения |

**Что показано на экране**

- вопрос задачи «Чья рыба?» и ответ — национальность владельца рыбы;
- номер и текст текущей подсказки;
- таблица с состоянием всех 5 домов;
- количество шагов без возвращения и с возвращением.

**Выход из программы**

При закрытии окна появляется запрос подтверждения: «Да» или `Enter` — выйти, «Нет» или `Escape` — остаться.

**Повторный запуск без перекомпиляции:**

```sh
./bin/refalabeinsteinpuzzle_gui          # POSIX
bin\refalabeinsteinpuzzle_gui.exe        # Windows
```
